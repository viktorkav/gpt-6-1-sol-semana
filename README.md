# Cinco peças web — entrega revisada

Este bundle contém os quatro sites e o jogo, prontos para abrir localmente. Não é preciso instalar Node ou compilar.

Na pasta extraída:

```sh
python3 -m http.server 48600 --bind 127.0.0.1
```

Abra:

- http://127.0.0.1:48600/home-viktorkav/
- http://127.0.0.1:48600/festival/
- http://127.0.0.1:48600/modelo-fronteira/
- http://127.0.0.1:48600/sistema-agentico/
- http://127.0.0.1:48600/roguelike-tatico/

O festival, o modelo/laboratório, o sistema operacional e seus benchmarks são conceitos fictícios; as demonstrações executam no navegador. O catálogo da home é um snapshot real datado, não um feed ao vivo.

As imagens de execução são as da entrega. As páginas de documentação do Trama foram resumidas na cópia pública para preservar os links da interface sem distribuir documentos privados, logs, capturas ou feedback. Código visual, motor e cores são os da revisão entregue.

Consulte os documentos DIREITOS-E-ORIGENS.md de cada peça. O pacote não concede licença geral ou autorização de uso das fotografias de artistas. Os prompts originais e o feedback ficam na Régua, exclusiva para membros.
