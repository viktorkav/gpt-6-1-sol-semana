Visão geral

Nór Research é um laboratório inventado. Aresta 01 é um conceito de modelo de IA de fronteira, sem pesos treinados, inferência, API ou disponibilização comercial. Esta página é uma peça de lançamento fictícia produzida para ViktorKav.

O laboratório interativo executa dois algoritmos de busca de caminhos e uma regressão linear. As entradas são editáveis e os resultados são calculados, não respostas pré-definidas apresentadas como chamadas a IA.

DADOS FICTÍCIOS DO CONCEITO

Critério e esforço

A comparação apresenta os modos hipotéticos Direto e Deliberado do mesmo Aresta01. Nenhum modelo foi executado. Tarefas, critérios, contagens e orçamentos foram inventados pelo autor para explicar uma escolha de produto.

São nove tarefas em três eixos: raciocínio, código e evidências. Cada tarefa representa 50 casos hipotéticos por modo, 150 por eixo e 450 no total. Um caso só seria aprovado ao satisfazer todos os critérios descritos. As porcentagens são calculadas das contagens inteiras; a agregação soma aprovados e divide pelo total de casos.

O esforço é um orçamento abstrato atribuído por caso. Não significa tokens, segundos, custo ou consumo real. A média é ponderada pelos casos de cada tarefa. Os números atribuem mais sucesso e de duas a quatro vezes o esforço ao modo Deliberado; essa relação narrativa não prevê desempenho real.

Filtros, seletor de métrica e modos recalculam as marcas e os dados exportados. O arquivo JSON inclui premissas, filtros, critérios, contagens e agregações. Você pode baixar também o módulo editável de dados e cálculos.

MÉTODOS EXECUTADOS

Planejar um caminho

Mapa de 18 colunas por 12 linhas, vizinhança de quatro direções, custo de cada movimento igual a 1. Origem e destino fixos; paredes editáveis. Os cenários são sintéticos.

Dijkstra escolhe o nó aberto com menor distância acumulada. A* soma a distância acumulada à estimativa Manhattan até o destino. Como a estimativa é admissível e consistente nesta grade, as duas buscas encontram uma rota mínima quando há solução.

O critério de desempate é a ordem de inserção: direita, cima, baixo, esquerda. Diferentes desempates podem mudar o número de células exploradas e escolher outra rota de mesmo custo. Não é garantido que A* explore menos nós em toda entrada.

Movimentos é o custo da rota, equivalente ao número de células do caminho menos 1. Células exploradas conta nós removidos do conjunto aberto, incluindo origem e destino. A animação apenas reproduz a ordem calculada; seu tempo não mede latência do algoritmo.

Se não existe rota, o motor retorna found: false, cost: null e lista vazia de caminho. A falha é parte do resultado.

Investigar os dados

CSV com duas colunas numéricas: tamanho de lote (unidades) e tempo de processo (minutos). Cabeçalho opcional e ao menos três observações. Ponto decimal; vírgula separa colunas. Não há upload ou envio remoto.

ŷ = a + bx
b = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)²
a = ȳ − bx̄

A regressão por mínimos quadrados minimiza a soma dos resíduos ao quadrado. O R² descreve quanto da variação observada é explicada pelo ajuste nessa amostra. Não é uma probabilidade de acerto. Se y é constante, o protótipo usa a convenção R² = 1 para ajuste exato.

RMSE é √(Σresíduo² / n), erro do ajuste dentro da amostra. Não é uma estimativa independente do erro futuro. A previsão para lote 12 é pontual; quando 12 está fora do intervalo de x observado, ela extrapola. Nenhum intervalo de confiança é calculado.

O diagnóstico de influência recalcula a inclinação removendo cada observação. Se a maior alteração relativa à inclinação sem o ponto alcança 25%, exibe um alerta. Esse limiar é didático, não um teste estatístico de outlier. Uma inclinação de referência próxima de zero pode produzir uma alteração relativa infinita; não confundir esse caso com certeza estatística.

O experimento aceita até 200 observações e 50.000 caracteres para manter a análise responsiva. São rejeitados CSV vazio, linhas inválidas, números não finitos, menos de três pontos, x constante e estouro numérico. Um ponto influente pode ser válido. Correlação não implica causalidade.

Dados e privacidade

A aplicação executa os cálculos no navegador. Não há analytics, formulário de cadastro, cookies de rastreamento ou API de IA. Fontes, código e arte são servidos localmente. A exportação gera um arquivo na máquina do visitante.

Os links externos só abrem os sites de referência quando acionados. A ferramenta de desenvolvimento Vite estabelece conexão local para recarregamento; a versão de produção não usa esse mecanismo.
