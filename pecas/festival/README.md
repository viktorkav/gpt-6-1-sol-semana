# Contra-Maré

Festival e lineup conceituais em Recife. Os 12 artistas são reais; evento, presença, datas, horários, palcos e ingressos são fictícios. Agenda, favoritos, conflito e exportação ICS executam no navegador.

Esta é a entrega revisada em 7 de outubro de 2026, parte do experimento de sete peças com GPT-6.1 Sol. Configuração solicitada: `gpt-6.1-sol`, `ultra`, `priority`; não há recibo independente do backend. A exportação adapta apenas o empacotamento e as instruções. O código visual e os assets de execução foram preservados.

## Executar

Requer Node.js 22.12+ ou 24+.

```sh
npm ci
npm run dev
```

Abra `http://127.0.0.1:4187/`. Para gerar o site estático, execute `npm run build`.

Não há venda, contratação ou pagamento. A agenda fica no navegador/origem. BaianaSystem e Luedji Luna na sexta demonstram um conflito de 45 minutos. A página `public/referencias.html` registra artistas e repertório de Ultra, Coachella, Lollapalooza e Rock in Rio.

Consulte [direitos e origens](DIREITOS-E-ORIGENS.md). Os prompts e o feedback ficam na Régua para membros; não estão nesta distribuição.
