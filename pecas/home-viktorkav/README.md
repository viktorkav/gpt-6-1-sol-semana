# Home ViktorKav

Home editorial com trilhas IA/Games/Construir, busca e um catálogo datado de 367 conteúdos reais.

Esta é a entrega revisada em 7 de outubro de 2026, parte do experimento de sete peças com GPT-6.1 Sol. Configuração solicitada: `gpt-6.1-sol`, `ultra`, `priority`; não há recibo independente do backend. A exportação adapta apenas o empacotamento e as instruções. O código visual e os assets de execução foram preservados.

## Executar

Requer Node.js 22.12+ ou 24+.

```sh
npm ci
npm run build
npm run dev
```

Abra `http://127.0.0.1:4173/`. A pasta `dist/` produzida pelo build usa caminhos relativos.

O catálogo é um snapshot de 28/09/2026, não um feed em tempo real. Marca, retrato, imagens e URLs pertencem ao ecossistema do canal. As duas artes da abertura usam `gpt-image-2.5-sunburst`; o manifesto público conserva somente modelo, dimensões e hashes necessários ao build. Referências: [canal](https://youtube.com/@vkav), [site](https://viktorkav.com.br/) e [GitHub](https://github.com/viktorkav).

Consulte [direitos e origens](DIREITOS-E-ORIGENS.md). Os prompts e o feedback ficam na Régua para membros; não estão nesta distribuição.
